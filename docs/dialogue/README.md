# Dialogue Evidence

This directory holds durable WastelandForge dialogue evidence packs and
implementation decision checklists.

Gate 56 creates the first evidence-pack skeleton:

- `response-route-taxonomy-evidence-pack.md` - checklist and evidence table
  for deciding dialogue response route taxonomy, selection behavior, Speech
  Challenge routing integration, and GECK/plugin mapping.

Evidence packs are not source contracts, schemas, generated outputs, or public
fixtures. They record the research and direct inspection needed before Forge
turns open dialogue behavior into schema, validation, generator, or CLI
behavior.

Public evidence must stay redistributable. It may record structural
observations, source names, field names, identifiers, hashes, and paraphrased
findings, but it must not commit shipped game assets, copied dialogue text,
private install files, or third-party mod files without explicit permission.
