# Architecture Decision Records

ADR-006 through ADR-011 are binding decisions from the completed research
foundation. ADR-012 records the accepted premium Windows app shell direction.
ADR-013 permits approval-bound external record-authoring providers while
retaining ADR-004's prohibition on raw plugin writing in Forge core.

These files are skeleton ADR records for implementation. They preserve the decision text and implementation consequences while the codebase is built gate by gate.
