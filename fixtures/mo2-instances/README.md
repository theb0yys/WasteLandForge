# Synthetic MO2 instance fixtures

These fixtures contain no Mod Organizer, Bethesda, or third-party binaries or
assets. They model only the redistributable configuration subset authorized by
Gate 396 from official MO2 source revision
`efe2a02d5dc641946baaa8db1440800f38d07837`.

Supported discovery fields are `[Settings] base_directory` and
`[Settings] mod_directory`. `%BASE_DIR%` is the only expansion token.
