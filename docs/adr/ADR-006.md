# ADR-006 - Hybrid Capability Platform

Status: Accepted
Research classification: Documented
Source: `WasteLandForge/research/Wasteland Forge Platform Architecture & System Design-deep-research-report.md`

## Decision

WastelandForge adopts a hybrid capability platform architecture.

The core lives outside the game and owns contracts, registries, validation, generation, documentation, packaging metadata, release automation, and capability rules. Existing ecosystem tools remain providers and integrations, not systems WastelandForge replaces.

## Consequences

- Forge owns source contracts and derived outputs.
- Forge integrates with GECK, xEdit, MO2, xNVSE, and related providers where appropriate.
- Forge does not replace GECK, xEdit, MO2, xNVSE, Blender, NifSkope, DAWs, or raw plugin editing.
- Capability and provider work is modeled explicitly before generators rely on environment behavior.

## Gate Impact

Gate 1 records the platform boundary. Gate 2 and later must keep implementation projects aligned with this ownership split.
