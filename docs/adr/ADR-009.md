# ADR-009 - Generator and Build Pipeline Architecture

Status: Accepted
Research classification: Documented
Source: `WasteLandForge/research/WastelandForge Generator and Build Pipeline Architecture-deep-research-report.md`

## Decision

WastelandForge outputs are generated through a deterministic, capability-aware build graph.

Generated artifacts are disposable and rebuildable. Every output must carry provenance, at minimum through a local build manifest once build work exists.

## Consequences

- Build inputs must be declared and traceable.
- Generated outputs belong under `generated/` or `dist/`.
- Clean operations must target generated outputs only unless explicitly authorized.
- Build manifests are mandatory for build/release gates.
